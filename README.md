# MemoryLab · 长期记忆实验

本机独立聊天应用：完整原话、图片和语音受管保存，按来源检索，支持纠正、7 天回收站、范围导出和本人格快照。默认单机单用户、一个人格；不依赖或修改 QQBot。

## 启动

本机环境准备完成后，双击 **启动实验版.cmd**。后端就绪后自动打开网页，只监听 `127.0.0.1:8765`。关闭网页不会关闭服务，请点网页侧栏“退出本地服务”；启动控制台也可按 Ctrl+C 退出。端口冲突不会结束其他进程。

默认使用**模拟模型**，其回答用于验证流程，不具备真实聊天或语义理解能力。在“设置 → 模型连接”切换为兼容聊天接口，填写 API 基址（通常以 `/v1` 结尾）和密钥。可先获取模型列表，再选择或手填模型 ID，最后“验证并启用”。粘贴完整 `/chat/completions` 或 `/models` 地址会自动还原为基址；不会猜测或补上 `/v1`。

“测试回复”用固定短文本验证文字流式聊天，不发送历史、人格或附件，也不保存测试对话；测试通过不会切换当前连接。启用时也会测试，远程服务可能收取少量调用费用；整理模型单独配置时也会测试。模型列表接口不可用时仍可手填模型名测试。图片及语音能力需按服务实际情况设置，文字测试不会认证媒体能力。

高级设置中的“单次请求最长等待”默认 180 秒，可设为 30–600 秒，包含一次模型请求的排队、推理和正文传输。聊天及单独配置的整理模型分别计时。收到完整回答的完成标记后即结束，不再等待网关关闭连接。超时会说明是连接阶段、尚无响应头、尚无正文、仅有推理片段还是正文未完成，不记录或展示推理内容；未完成草稿不保存，也不自动重试。超时不保证通过增加时限就能解决，仍需检查实际模型服务与网络。

硅基流动 Qwen3.5 系列可在高级设置选择思考模式：服务默认、关闭或开启。为了避免启用前的简短连通测试进行长时间推理，这个系列的基础回复测试显式关闭思考；测试结果会标明未验证开启思考时的耗时。日常聊天、整理及图片描述按设置执行。此扩展参数仅发往 `api.siliconflow.cn` 或 `api.siliconflow.com` 的 `Qwen/Qwen3.5-*` 模型，其他服务不发送。可先选择“关闭思考 · 直接回复”验证日常聊天，再按需要开启。

地址、模型和参数会保存，密钥只保存在进程内存。同一当前地址留空密钥可沿用已有值，换地址不会转发原密钥；无认证本机服务可留空。可显示/隐藏新输入的密钥，也可“清除密钥并停用”回到模拟模型。重启后需要重新填写密钥并启用远程服务。不会自动查找本机其他程序的密钥，也不会自动跟随重定向转发凭据。

网页保存双方完整消息和实际发送的附件。用户消息先保存，完整回答完成后保存。停止生成会丢弃草稿，已经收到的用户消息继续保留。“暂停保存”仍可读取旧记忆，期间交流只存在内存和受管临时附件中；重新开启后清空临时上下文，不补存。

## 首次准备与本地语义模型

本项目使用独立 Python 3.12.15、uv 锁定依赖，运行环境、缓存、模型和临时目录均在 `.local/`。已有 uv 时双击 **准备环境.cmd**，不修改系统 Python、Ollama 或原 Bot 环境。项目移动后先重新准备环境；这不是便携发行包。

在项目终端准备公开 BGE-M3：

```powershell
.\.local\runtime\venv\Scripts\python.exe scripts\prepare_memory_lab.py --embedding --skip-sync
```

若官方模型站连接被重置，可以显式选择公开镜像并使用分块续传：

```powershell
.\.local\runtime\venv\Scripts\python.exe scripts\prepare_memory_lab.py --embedding --skip-sync --endpoint https://hf-mirror.com --revision 5617a9f61b028005a4858fdac845db406aefb181 --ranged-download
```

权重约 2.14 GiB，运行依赖和模型另需空间，建议预留至少 10 GiB。模型准备清单记录版本、文件大小、下载来源及权重摘要。完整准备后启动会自动接上本地模型，首次检索需要加载；也可在设置页加载。运行时只从项目内加载文件，不自动联网下载。当前锁定的是 CPU 推理环境，未启用或验证 GPU 加速。

原文、编号、中文短词、时间和会话搜索不依赖 embedding。语义模型不可用时显示降级说明，已保存原话仍可检索。经历整理使用当前配置的聊天／整理模型；默认模拟整理会明确标记。

## 记忆、媒体与数据操作

- 对话中可展开原文前后文和“本次历史来源”；该清单只说明实际提供的资料，不证明模型内部使用了某条来源。
- “纠正 / 变化”保留旧原话并关联修订；已知事件日期可选填。语音转写和图片描述可单独修正，不覆盖原始媒体。
- 遗忘默认选中整个问答轮，确认前可调整。只处理所选消息及直接派生内容，其他对话的独立提及不会自动删除。
- 回收站保留 7×24 小时，可恢复、提前永久清理或清空。未运行时不进行定时清理；下次启动先屏蔽到期内容并处理清理。旧快照恢复不延长期限，也不能复活永久删除记录。
- 支持 JPEG/PNG/WebP 图片（20 MiB）及 WAV/MP3/M4A/OGG 语音（25 MiB、10 分钟），每条最多 6 个附件。识别服务可选；未配置时显示“尚未识别”，仍可查看、播放原文件。
- 远程模型能力在设置中明确配置。原始媒体仅在适配器支持时按受限 ID 读取发送；来源清单说明发送的是原文件、识别文字还是未识别。不会发送本机目录路径冒充媒体。
- 导出默认当前会话，包含 MD、JSONL 和有来源的经历阅读版；可选人格阅读版和附件。附件包含在导出目录内，文本中使用相对链接。程序内导出受删除追踪管理，自行复制出去的副本需手工管理。
- 手工快照包含程序管理的人格源、原文及媒体，不含向量；恢复先校验再切换，并应用当前生命周期清单。恢复不是合并，会回到该恢复点，操作前可另建快照。
- `users/` 由你自行维护；程序不读取、枚举、监视、索引、导出或备份。清理记忆不应递归删除人格根目录。

当前不提供模型任意工具调用、文件访问、自由 SQL、账号系统、QQ 接入、定时备份或公网部署。

## 验证

所有验证使用独立合成目录：

```powershell
.\.local\runtime\venv\Scripts\python.exe scripts\verify_memory_lab.py
.\.local\runtime\venv\Scripts\python.exe scripts\benchmark_memory_lab.py --sizes 10000 100000 1000000
.\.local\runtime\venv\Scripts\python.exe scripts\evaluate_semantic.py
```

结果位于 `.local/verification/` 和 `.local/benchmarks/`，不使用真实聊天数据。验收现状见 [docs/acceptance.md](docs/acceptance.md)，接口及存储约定见 [docs/interfaces.md](docs/interfaces.md)、[docs/storage.md](docs/storage.md)。远程服务真实联调需要用户配置，不能以模拟响应代替真实模型验收。

开发启动时必须显式指定本项目内数据目录：

```powershell
.\.local\runtime\venv\Scripts\python.exe -m memory_lab --data-root E:\MemoryLab\.local\data --port 8765
```

诊断默认不落聊天正文、密钥或草稿。凭据检测仅覆盖若干常见格式，不能保证发现所有秘密；请勿在对话中发送密钥。永久清理是本程序受管文件的清理，不是 SSD 或外部备份的取证级擦除。
