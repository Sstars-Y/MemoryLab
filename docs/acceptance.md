## 已修复的问题

- 跨会话只取旧状态：对命中记录补读连续后续说明，包括已识别语音；结合原话与变化，按时间提供来源。
- 无关图片串入：逐消息相关性过滤与重排，图片还需话题联系或明确媒体请求；换话题和未识别媒体形成边界。
- 大量旧匹配挤掉新状态：同时取得相关度与近期匹配，最终上下文按记录时间排序。
- 识别文字搜索及恢复后索引丢失：统一索引原话、修订及识别文字，启动、回收站恢复、旧快照恢复均补修索引。
- 模型虚报更新或否认已经保存：宿主提供当轮真实保存回执，明确区分原始记录保存、识别、整理、事实纠正和提醒。
- 明确追问助手建议却漏掉助手原话：引用型问题按助手来源检索，去掉引用说明等问句套话；保留原话标注，普通事实问题不把助手旧回复提升为用户事实。
- 百万完整聊天召回超时：全文候选与向量扫描并行，结束后锁内重查来源；一次重排对相同文本只编码一次，保留独立消息身份，修订与识别文字参与区分。删除和索引切换期间的迟到结果有专门回归。

## 现在如何手工验收

先退出旧服务，再双击`E:\MemoryLab\启动实验版.cmd`，让8765实例加载修复。旧真实实例没有被本轮擅自重启。密钥只在进程内，重启后需在设置重新填写并启用远程模型。用独立验收会话和自选虚构代号操作。

1. **跨会话变化**：先说测试物品在甲处，再说“后来把它移到乙处”。新会话分别问最初与当前位置；打开本次历史来源，核对原话与变化。
2. **图片隔离**：另一个会话发送无关测试图片；回到物品问题，回复和来源都不应混入该图片。明确追问图片时再检查相关图片来源。
3. **助手原话**：让助手给一个测试建议，新会话问“你上次建议的……是什么”。核对来源确为助手原话；不能将其当成已经执行操作的凭据。
4. **语音**：上传已知内容的录音，核对附件编号和播放器；点击识别/重试，检查转写，再从新会话按内容提问。修订转写后，原文件应不变。
5. **纠错**：分别提交“原记录错误”和“后来发生变化”，核对类型、旧原话与当前状态。
6. **回收站**：预览并只选合成记录，遗忘后搜索/聊天/普通播放不可用；恢复后原编号与字节不变。永久清理仅对可丢弃的合成记录操作。
7. **导出/快照**：检查选择范围和原媒体；建立快照后改动合成记录再恢复，已永久清理内容不能复活，回收站期限不能延长。

### 暂停保存的详细验收

“暂停保存”控制本地长期记录；远程回答仍需发送当前输入。暂停时允许读取以前已保存的记忆。

1. 正常保存一条虚构对照，记下消息数及一个可搜索的旧代号。
2. 点击暂停保存，确认界面显示临时交流；在生成途中切换开关时检查未完成草稿被取消。
3. 发送新的唯一临时代号，再问“我刚才说的临时代号是什么”。同会话能临时回答属于正常行为；暂停期间长期消息数不应增长。
4. 可上传一张可丢弃测试图片，检查暂停期间仅用于临时交流，不能形成长期附件记录。
5. 重新开启保存，临时上下文清空、不补存；提问时不要再次写出临时代号，避免把测试词作为一条新正常消息保存。
6. 新会话询问刚才临时内容，来源不应带入；正常旧代号仍可回忆。仍能回忆旧事不代表暂停失效。
7. 原文搜索临时代号应无结果；范围导出、快照及后台整理不得包含它。测试附件在临时交流结束后清理。
8. 退出并重启，新会话再检查；仅正常保存的对照仍可查到。之后正常发送的新消息会增加消息数，不应误用最初计数比较所有后续操作。
